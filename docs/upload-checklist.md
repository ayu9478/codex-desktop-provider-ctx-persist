# 上传检查清单

推送到 GitHub 前，请确认：

1. 没有包含原始 `.codex` 文件。
2. 没有包含 API key、provider base URL 或认证文件。
3. 截图里只包含已遮盖的 thread id 和脱敏路径。
4. 仓库只包含：

   ```text
   README.md
   docs/
   screenshots/
   screenshot-pages/
   tools/
   .gitignore
   ```

5. 仓库名称能表达方案用途，例如：

   ```text
   codex-context-recovery-solution
   ```

6. 创建 GitHub 仓库后，把当前目录作为仓库根目录推送。

建议首次提交信息：

```text
docs: 添加 Codex 深度链接恢复方案
```
